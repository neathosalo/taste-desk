# PAIOS 品味台

品味台是一款在本机运行的视觉参考工作台。你可以比较几个设计方向，把喜欢的参考归入专题板，并将选择、用途和设计约束整理成可交给同事或 AI 助手的任务单。

## 运行

安装 Node.js 22 或更新版本。克隆仓库或下载源码 ZIP，在项目目录运行：

```sh
node server.mjs
```

用浏览器打开 http://127.0.0.1:4318 。端口被占用时可运行 `node server.mjs --port 4320`，再打开对应端口。按 Ctrl+C 停止服务。

## 试一次

1. 在「风格词典」打开模块网格和网格与大字两张卡，将它们加入对照。
2. 在「对照台」比较各自适用的内容，选好方向后放入专题板。
3. 到「创作参考」挑版式或画风，在「组合台」补上用途、主题和画幅，再导出任务。

## 版本范围

`v0.1.0` 是现版品味台的浏览器分享版，随附四张示例图及其参考卡，保留偏好留痕、对照、专题板、自有资产、待整理和任务导出。原工作库、第三方素材合集和 macOS 安装包独立维护。

用户状态和上传文件默认保存在 `local-data/`，任务导出在 `exports/`。可用 `TASTE_DESK_DATA_ROOT` 和 `TASTE_DESK_EXPORT_ROOT` 指定其它本机目录。这是单用户本地工具，服务绑定到回环地址。没有外部 API 或联网依赖。

建议通过 GitHub Issues 提报问题，并附上 Node.js 版本、操作系统和可复现步骤。
